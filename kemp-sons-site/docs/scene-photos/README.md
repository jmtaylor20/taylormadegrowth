# Home page 3D scene photos

AI-generated sample photos (no real people) used to render the Flag & Clouds
trifold that opens the home page: a veteran in dress uniform (and its cut-out
for the flag cover), his 1966 service photo, and a porch snapshot.

The rendered panels live in public/scene/trifold-*.jpg. To re-render, serve
these files at /scene/src/ in the dev server and render the template's
outside and inside sides with the designer's renderSide().
